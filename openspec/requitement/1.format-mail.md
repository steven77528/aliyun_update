# 修改邮箱通知格式

## 1. 需求背景

目前修改邮箱的通知邮件格式较为单一，无法满足用户个性化需求。为了提升用户体验，我们计划优化修改邮箱的通知邮件格式，使其更加美观、清晰，并且能够提供更多有用的信息。

## 2. 需求内容

1. 邮件主题为：`[阿里云安全组自动更新] ---- 更新通知`
2. 第一行：显示邮件内容，需要加粗加黑显示，内容如下：

```text
公网IP变更，安全组规则变更汇总通知
```

3. 第二行：显示生成时间，格式为“生成时间：YYYY-MM-DD HH:mm:ss”，其中YYYY-MM-DD HH:mm:ss为邮件发送的实际时间，如：

```text
生成时间：2024-06-01 14:30:00
```

4. 第三行：显示当前公网ip，如：

```text
当前公网IP：${ip}
```

5. 第四行：显示记录修改的统计信息，如：

```text
记录总数${total}，成功${success}，失败${fail}
```

6. 第五行：显示修改失败的记录详情，用表格的形式呈现，表格的头包括：序号、修改时间、账号、区域、安全组、规则、旧IP、新IP、结果、失败原因，表格中所有数据居中显示，每条记录的内容如下：

```text
序号：按序排列
修改时间：从修改记录中获取，格式为“YYYY-MM-DD HH:mm:ss”，为记录修改的时间
账号：从`aliyun.yaml`配置中的`accounts.account`的值获取
区域：从`aliyun.yaml`配置中的`accounts.region_id`的值获取
安全组：值在一个单元格中分两行显示，第一行显示安全组名称，取自`aliyun.yaml`配置中的`accounts.security_groups.alias`的值，第二行显示安全组ID，取自`aliyun.yaml`配置中的`accounts.security_groups.security_group_id`的值
规则：值在一个单元格中分两行显示，第一行显示规则名称，取自`aliyun.yaml`配置中的`accounts.security_groups.rules.alias`的值，第二行显示规则ID，取自`aliyun.yaml`配置中的`accounts.security_groups.rules.rule_id`的值
旧IP：从修改前的记录中获取
新IP：从修改后的记录中获取
结果：显示修改结果，成功显示“成功”，失败显示“失败”
失败原因：如果修改失败，显示失败的具体原因；如果修改成功，则该单元格显示为“-”
```

7. 邮件内容中，行间距设置为1.5倍，确保内容清晰易读。

## 邮件发送逻辑

1. 当用户修改邮箱后，系统会自动生成一封通知邮件，并按照上述格式进行内容填充。
2. 邮件内容将根据实际修改的记录进行动态生成，确保每次修改都能准确反映修改的结果和相关信息。
3. 邮件将发送到用户的注册邮箱，确保用户能够及时收到修改通知。
4. 如果修改过程中出现任何错误，系统将记录错误信息，并在邮件中详细说明失败原因，帮助用户了解问题所在并及时解决。
5. 如果ip修改的时间为22点到次日7点之间，不会立即发送邮件，待到次日7点时统一发送邮件，邮件内容中会显示修改的时间为实际修改的时间。
6. 每两个小时只发送一次邮件，这个配置保持不变，确保用户不会因为频繁修改而收到过多的邮件通知。
7. 22:00-07:00之间，如果有多次修改，邮件内容中会显示所有修改的记录，并且修改时间为实际修改的时间。
