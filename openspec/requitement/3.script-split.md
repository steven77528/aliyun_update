# 脚本拆分

## 1. 需求背景

目前脚本的功能较为集中，随着功能的增加，代码的可维护性和可扩展性逐渐降低。为了提升代码质量和开发效率，我们计划将现有脚本进行拆分，将不同功能模块独立出来，使代码结构更加清晰，便于后续的维护和功能扩展。

## 2. 需求内容

将现有脚本按照功能模块进行拆分，至少拆分为以下几个模块：

- 配置管理模块：负责读取和管理配置文件，如 `aliyun.yaml`。
- IP地址管理模块：负责获取当前公网IP地址，并与之前记录的IP地址进行比较。
- 安全组规则更新模块：负责根据IP地址变化情况更新阿里云安全组规则。
- 邮件通知模块：负责生成和发送邮件通知，包含修改邮箱通知格式的需求。
- 日志管理模块：负责生成和管理日志文件，包含日志整改的需求。

每个模块应独立成一个文件，模块之间通过函数调用进行交互，确保代码的高内聚和低耦合。
